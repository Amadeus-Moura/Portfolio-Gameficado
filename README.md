## 📜 Sobre o Projeto
Este repositório contém meu portfólio pessoal construído como uma experiência imersiva baseada na interface do aclamado anime **Sword Art Online (SAO)**. A ideia não é ser apenas um currículo digital, mas sim um menu interativo onde o usuário tem a sensação de estar imerso no ecossistema virtual de Aincrad. 

Foi desenvolvido focado em alta fidelidade visual, menus laterais característicos, barras de HP, efeitos de transição minimalistas e exibição gamificada dos projetos no formato de **"Inventário de Itens"**.

## 🚀 Funcionalidades
- **Menu SAO Style:** Navegação centralizada e minimalista utilizando iconografia geométrica e fontes estilizadas.
- **Inventário de Projetos:** Os projetos são categorizados por raridade (Lendário, Épico, Raro) através de modais com design "split-view" e inspeção detalhada de "itens".
- **Responsive HUD:** A interface se adapta para equipamentos móveis sem perder a estética virtual do anime.
- **Timeline de Experiência:** Experiências profissionais expostas como quests concluídas em uma linha do tempo vertical.

## 💻 Tech Stack
- **React.js** (v19) 
- **Vite** para build e desenvolvimento super-rápido
- **CSS3** avançado (Animations, Backdrop Filters, Flexbox/Grid)
- **React Router DOM**
- **Integração de Ícones SVG**
